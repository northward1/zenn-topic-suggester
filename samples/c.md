Markdown（マークダウン）の基本記法と、Zennで記事を書く際に使える独自の記法・拡張機能を整理して解説します。

---

## 1. Markdownの基本記法

文章を装飾したり、構造化したりするための標準的な記法です。

### 見出し

`#` の数で見出しの大きさを表します。Zennでは記事タイトルが `#`（H1）にあたるため、**本文中の見出しは `##`（H2）から始める**のが標準的です。

```markdown
## 見出し2（大見出し）
### 見出し3（中見出し）
#### 見出し4（小見出し）

```

### 太字・斜体・打ち消し線

テキストを強調したいときに使用します。

```markdown
**太字**
*斜体*
~~打ち消し線~~

```

### リスト（箇条書き）

先頭にハイフン `-` または数字を置きます。インデントを入れることで階層化できます。

```markdown
- リスト項目1
  - 子要素A
  - 子要素B
- リスト項目2

1. 順序付きリスト1
2. 順序付きリスト2

```

### リンクと画像

URLや画像を設定します。

```markdown
[表示テキスト](https://example.com)

![画像の代替テキスト](https://example.com/image.png)

```

### 引用

文頭に `>` をつけると引用ブロックになります。

```markdown
> 引用したい文章をここに書きます。

```

### コードとコードブロック

文中でのインライン表示はバッククォート ``` で囲み、複数行のプログラムコードは ``` で囲みます。

```markdown
文中に `const x = 10;` のように入れられます。

```javascript
function greet() {
  console.log("Hello, World!");
}
```

```

### テーブル（表）

パイプ `|` とハイフン `-` を組み合わせて作成します。

```markdown
| 機能   | 対応状況 |   備考 |
| ------ | :------: | -----: |
| 左寄せ | 中央寄せ | 右寄せ |
| 項目A  |    ○     |   補足 |

```

## 2. Zenn独自の記法・拡張機能

Zennでは、開発者向け記事を読みやすくするための独自のMarkdown記法が用意されています。

### メッセージボックス

読者の目を引く補足情報や警告を表示できます。

```markdown
:::message
ここには**補足情報**やTipsを書きます。
:::

:::message alert
ここには**注意点**やエラー回避方法などの警告を書きます。
:::

```

### アコーディオン（折りたたみ表示）

補足コードや長文を折りたたんで隠すことができます。

```markdown
:::details 長いログや詳細コードを開く
ここに隠したい内容を記述します。
Markdownの書き方もそのまま使えます。
:::

```

### コードブロックの拡張（ファイル名・diff表示）

言語名の後に `:ファイル名` を追加すると、コードブロックの枠上にファイル名が表示されます。また、`diff` 言語指定でコードの差分を強調表示できます。

```markdown
```typescript:src/index.ts
const message: string = "Hello Zenn";
console.log(message);
```

```diff typescript:src/index.ts
- const oldVersion = 1;
+ const newVersion = 2;
```

```

### リンクカード・SNS・サービスの埋め込み

URLを単独の行に貼り付けるだけで、各種サービスの埋め込みやリンクカードに自動変換されます。

```markdown
# 単独行にURLを貼るとリンクカード化
[https://zenn.dev](https://zenn.dev)

# YouTubeの埋め込み
[https://www.youtube.com/watch?v=XXXXXX](https://www.youtube.com/watch?v=XXXXXX)

# GitHub Gistやリポジトリの埋め込み
[https://github.com/octocat/Hello-World](https://github.com/octocat/Hello-World)

```

### 数式（KaTeX）

ドルマーク `$` を使うことで、数式を綺麗に描画できます。

```markdown
インライン表示: $e^{i\pi} + 1 = 0$

ブロック表示:
$$
\int_{a}^{b} f(x) dx = F(b) - F(a)
$$

```

### 注釈

単語の直後に `^[注釈文]` と書くことで、ページ下部に注釈を表示できます。

```markdown
Zenn記法^[Zennで採用されている特殊なMarkdown拡張]を使ってみましょう。

```

## 3. Zennで読みやすい記事を書くコツ

* **見出しは `##` から使用する**: H1（`#`）は記事のタイトル専用として扱われるため、本文の最初の見出しは `##` にします。
* **空行を適切に挟む**: 段落やコードブロック前後、見出しの前には1行空行を入れることで、意図しない記法のプレビュー崩れを防げます。
* **メッセージボックスや折りたたみを活用する**: 本文のテンポを崩さないよう、補足説明は `:::message` や `:::details` に切り出すと読者にとって読みやすくなります。
